  • Async FastAPI services chained speech-to-text, retrieval and intent, then speech synthesis, for a low-latency conversation loop.

Go · Local LLMs

docgen

Documentation tooling that starts from facts instead of guesses. It extracts what a codebase actually contains without any AI, then holds every generated sentence to those facts.

  • facts and check extract symbols, flags and paths from the code and flag docs that disagree with it.
  • draft and ask use a local model to write overviews and answer questions, with every claim verified against the extracted facts.
  • gen writes Ansible, Terraform, Helm and CI boilerplate from retrieved module specs, and runs the real tools on it before anything is saved.
  • A scheduled job keeps generated docs current across repositories without ever touching hand-written text.

Go · CLI

clctl

A single-binary CLI for Linux, macOS and Windows that brings task tracking, timers, notes and comments into the terminal, rewritten from an earlier Python version.

  • AI digests of meetings, notes and coding-assistant sessions, written by a local model and filed next to the notes they summarise.
  • Semantic search over notes and task comments using local embeddings, re-indexing only what changed.
  • Shell completion that asks the binary itself for commands and task IDs, so it always matches the installed version.
